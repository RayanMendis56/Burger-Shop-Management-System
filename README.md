# 🍔 Burger Shop Management System

A simple **Java-based Burger Shop Management System** developed as a console application. The project demonstrates fundamental Java programming concepts including classes, objects, arrays, methods, loops, conditional statements, and user input.

---

## 📌 Project Overview

The **Burger Shop Management System** is a console-based application designed to manage burger orders in a simple and efficient way.

The application allows users to interact with a menu-driven system to perform different operations related to burger orders. It was developed as a practical project to strengthen fundamental Java programming and Object-Oriented Programming (OOP) concepts.

---

## ✨ Features

* 🍔 Add new burger orders
* 🔎 Search for existing orders
* 📋 View burger/order information
* 💾 Store multiple burger records
* 🧾 Manage order-related information
* 🖥️ Console-based user interface
* 📌 Menu-driven application
* 🧱 Object-oriented design using Java classes and objects

## 🚀 Getting Started

Follow the steps below to run the project locally.

### Prerequisites

Make sure you have the following installed:

* Java Development Kit (**JDK 8 or later**)
* Git
* A Java-compatible IDE or terminal

You can verify your Java installation using:

```bash
java -version
```

and:

```bash
javac -version
```

---

## 📥 Clone the Repository

Clone the repository using:

```bash
git clone https://github.com/RayanMendis56/Burger-Shop-Management-System.git
```

Navigate into the project directory:

```bash
cd Burger-Shop-Management-System
```

---

## ▶️ Running the Project

### Using the Terminal

Compile the Java source files:

```bash
javac Main.java BurgerShop.java
```

Then run the application:

```bash
java Main
```

### Using an IDE

The project can also be opened using a Java-compatible IDE such as:

* IntelliJ IDEA
* Eclipse
* NetBeans
* Visual Studio Code

Open the project, locate `Main.java`, and run the `main()` method.

## 🧠 Programming Concepts Demonstrated

This project was developed to practice and demonstrate several fundamental programming concepts in Java.

### Variables and Data Types

The application uses Java variables and different data types to represent and manage burger and order information.

### Classes and Objects

The project uses classes to organize related data and functionality and demonstrates the basic principles of Object-Oriented Programming.

### Arrays

Arrays are used to store and manage multiple burger/order records.

### Methods

Different methods are used to divide the application functionality into manageable sections and improve code organization.

### Conditional Statements

`if`, `else if`, and `else` statements are used to make decisions based on user input and application conditions.

### Loops

Loops are used to repeatedly display menus, process user input, and perform operations on multiple records.

### User Input

The application uses console input to allow users to interact with the system.

### Menu-Driven Programming

A menu-based interface allows users to select different operations and interact with the burger shop system.
